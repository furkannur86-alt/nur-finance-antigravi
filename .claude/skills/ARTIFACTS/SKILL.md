# /ARTIFACTS — Financial Artifact Generator

Generate and publish interactive financial artifacts (HTML pages) for NUR Finance. Use the Artifact tool to create shareable, professional financial content.

## Artifact Types

### Market Dashboard
- Real-time-styled market overview with indices, FX, commodities
- Interactive charts, heatmaps, sector performance
- Use NUR Finance brand: red (#cc0000), black (#0a0a0a), white (#ffffff)

### Risk Report
- VaR analysis, stress test results, correlation matrices
- Contagion maps, liquidity stress indicators
- Professional institutional-grade layout

### Portfolio Analysis
- Holdings breakdown, allocation pie charts, P&L waterfall
- Benchmark comparison, risk-adjusted returns
- Sharpe, Sortino, Calmar ratios

### Market Brief
- Executive summary of market conditions
- Key macro indicators, central bank watch
- Sector rotation, earnings calendar highlights

### Pricing / Sales Page
- NUR Finance terminal pricing tiers
- Feature comparison table
- Professional, credible institutional design

## Design Rules
- Bloomberg-inspired dark theme with modern UX
- Font: system monospace for data, clean sans-serif for text
- Brand colors: red accent, black background, white text
- Dense but readable — financial professionals expect information density
- All content in English
- No fantasy, space, or non-finance content
- Mobile-responsive

## Workflow
1. Ask what type of artifact is needed (or infer from context)
2. Build the HTML page with inline CSS/JS
3. Publish via Artifact tool
4. Share the link
